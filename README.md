# 🌸 PerfumeTrending.cl — Capstone Project (APT122)

> Plataforma web inteligente para la comparación de precios, detección de tendencias mediante IA y verificación antifraude e-commerce en el mercado chileno de perfumería.

## 📂 Estructura del Repositorio

El proyecto se organiza en tres fases académicas con entregables individuales y grupales:

- **`Fase_1/`**: Definición, fundamentación, matriz de riesgos, diagrama de Ishikawa y autoevaluaciones iniciales.
- **`Fase_2/`**: Desarrollo del software, avances de código, diagrama PERT y documentación de arquitectura.
- **`Fase_3/`**: Cierre de proyecto, producto final consolidado y evaluaciones finales.

---

## 🛠️ Stack Tecnológico

- **Frontend:** Streamlit / Python
- **Backend & Scraping:** Python, BeautifulSoup, Selenium, Requests, APIs REST
- **Base de Datos:** PostgreSQL
- **IA / Análisis de Datos:** YouTube Data API, pandas, scikit-learn
- **Control de Versiones & CI/CD:** GitHub Actions / Streamlit Community Cloud

---

## 🎯 Módulos Principales

- **Comparador de Precios:** extracción y actualización periódica de precios y stock desde tiendas de perfumería chilenas mediante Web Scraping.
- **Trust Score:** índice de evaluación de transparencia y legitimidad de comercios electrónicos.
- **Hype Radar:** análisis del volumen de menciones de fragancias en YouTube y su tasa de crecimiento semanal, con arquitectura extensible a otras redes sociales.
